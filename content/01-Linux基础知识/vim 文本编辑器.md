# 模式mode
    - Vim基础回顾
        * 打开Vim：直接输入`vim`或`vim 文件名`
        * 退出Vim：命令模式`:q`，强制退出`:q!`
        * 模式切换
            + 正常模式：默认模式，可移动光标
            + 插入模式：按`i`进入，按`Esc`返回正常模式
            + 命令模式：按`:`进入，执行保存/退出等操作
        * 常用命令
            + 保存：`:w`
            + 保存并退出：`:wq`
            + 不保存退出：`:q!`
    - Vim新知识点
        * 缓冲区（Buffer）
            + 打开Vim至少有一个缓冲区
            + 可理解为打开的文件（新建/已存在）
            + 用于编辑文本的区域
        * 正常模式进阶操作
            + 删除字符：`x`
            + 删除整行：`dd`（其实这个理解为剪切更好，因为删除同时也会将这行复制到粘贴板）
            + 撤销操作：`u`
            + 光标移动：`h`左/`j`下/`k`上/`l`右
        * 命令模式扩展
            + 合并文件：`:r 文件名`（读取文件内容插入当前缓冲区）
            + 另存为：`:w 新文件名`
            + 执行Linux命令：`:! 命令`（执行后返回Vim）

# <font style="color:rgb(24, 25, 28);">配置文件</font>
    - Vim 配置与行号
        * 临时显示行号：`:set number`
        * 临时隐藏行号：`:set nonumber`
        * 永久生效配置
            + 配置文件：`~/.vimrc`（隐藏文件）
            + 写法：`" 注释` + `set number`
        * 从指定行打开文件：`vim +行号 文件名`

```bash
" 自定义vim的配置
set number
```

    - 编辑快捷操作
        * 删除整行：`dd`（自动复制到粘贴板）
        * 粘贴：`p`
    - 缓冲区操作
        * 切换缓冲区：`:bp`（上一）、`:bn`（下一）
        * 编辑文件（新缓冲区）：`:e 文件名`
        * 删除缓冲区：`:bd`
        * 添加缓冲区：`:badd 文件名`
    - 分屏启动
        * 水平分屏：`vim -o 文件1 文件2`
        * 垂直分屏：`vim -O 文件1 文件2`
    - 系列说明
        * 日常使用 Vim 核心内容完结
        * 可自定义更多配置，进阶技巧待探索
